FACT: Halos source location
├─ Packages: psf-desktop.deb and psf-desktop-dev.deb (access-restricted on NGC)
├─ Expected extraction path: /opt/nvidia/psf/examples/apps/metropolis/
├─ Key files:

│  ├─ cmd_rx.cpp (command receiver)
│  └─ SafetyElementInterface.cpp (decision logic)
└─ Status: Not inspected (access-restricted)

FACT: ATL command packet is exactly 64 bytes
├─ Magic: 0x41544C01 (ASCII "ATL" + version)
├─ Opcode: 32-bit field (CMD_MUTE, CMD_UNMUTE, CMD_SAFE_RELEASE_*, CMD_SW_ERROR)
├─ CRC: 32-bit CRC-32 over bytes 0–55
├─ Sequence: 32-bit replay protection counter
├─ Timestamp: 64-bit millisecond freshness field
└─ Full structure documented in packet-format.md

FACT: Execution path is SIPP → SAIM/PCM → SEI → SDM → ATL Receiver
├─ SIPP: External sensor input (not Safety Core)
├─ SAIM/PCM: Perception integration (Safety Core)
├─ SEI: Authoritative safety decision (Safety Core)
├─ SDM: Semantic Decision Module, generates 64-byte packet (Safety Core)
├─ [SLC GATE INSERTION POINT] ← Independent authority enforcement
├─ ATL Receiver: UDP command receiver (Safety Core)
└─ Safety Function: Command dispatch and execution (Safety Core)

INFERENCE: SLC provides orthogonal enforcement
├─ Halos answers: "Is it currently safe/permissive?"
├─ SLC answers: "Does execution authority currently exist?"
├─ Both must be true for command to reach downstream execution boundary
├─ Halos validates: Safety decision, packet integrity, freshness
├─ SLC validates: Authority binding, governance context, execution epoch
└─ Failure modes are independent and measurable

PROPOSAL: SLC gate architecture
├─ Location: Between SDM packet generation and ATL receiver ingress
├─ Mechanism: SHA-256 binding of exact 64-byte packet to authority record
├─ Authority binding includes: context, epoch, TTL, target device
├─ Decision: ALLOW (forward unchanged) or BLOCK (drop packet)
├─ Epoch management: Governance system controls epoch; epoch mismatch → BLOCK
├─ Measurement: Receiver ingress packet count shows SLC effectiveness
└─ Halos unmodified: No changes to safety decision, packet structure, or CRC

================================================================================
DISTINCTIVE FEATURES
================================================================================

1. Byte Preservation
   ├─ On ALLOW: Original packet forwarded byte-for-byte (no modification)
   ├─ On BLOCK: Zero bytes sent (measurable at receiver)
   └─ Implication: Halos safety logic remains untouched

2. Authority Independence
   ├─ Authority bound to: SHA-256(exact_64_bytes) + context + epoch
   ├─ Epoch mechanism: Governance system advances epoch to revoke authority
   ├─ Result: Same packet bytes cannot be replayed after epoch change
   └─ Not a replacement for Halos freshness/sequence checks

3. Measurable Enforcement
   ├─ SDM packet emission: Logs show packet was generated
   ├─ SLC decision: Logs show ALLOW/BLOCK and reason
   ├─ Receiver ingress: Packet count shows whether packet reached receiver
   ├─ Decisive test: Epoch revocation blocks packet without Halos change
   └─ Evidence is auditable and independent

4. Minimal Modification Surface
   ├─ Only insertion point: SDM → transport boundary
   ├─ No modification of: Packet structure, safety logic, receiver validation
   ├─ Reference implementation: ~200 lines of Python
   └─ Integration: Wrapper class or socket hook (both clean approaches)

================================================================================
DECISIVE EXPERIMENT
================================================================================

Goal: Prove SLC enforcement is independent from Halos safety decisions

Setup:
  1. Halos SDM permits operation (CMD_UNMUTE)
  2. SLC issues authority for that packet under epoch 481
  3. Governance allows the route
  4. Packet is forwarded to receiver → Motor enables

Trigger:
  5. Governance epoch advances: 481 → 482
  6. Authority for the old packet is now stale (epoch mismatch)

Test:
  7. Exact same packet bytes are replayed/resent
  8. Halos safety logic: still permissive (would emit same packet)
  9. SLC gate: EPOCH_MISMATCH → BLOCK

Expected Results:
  ✓ Halos decision: PERMISSIVE (unchanged)
  ✓ Packet bytes: identical (no modification)
  ✓ Packet CRC: valid (integrity preserved)
  ✓ Receiver ingress: zero new packets (SLC blocked it)
  ✓ SLC log: EPOCH_MISMATCH at timestamp T

Conclusion:
  Command execution stopped by SLC authority enforcement, not by Halos safety logic.
  This demonstrates independent, complementary execution-authority enforcement.
